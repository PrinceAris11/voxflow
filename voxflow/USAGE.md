# VoxFlow usage guide

## Quick start

1. Open the project folder.
2. Run the server using the 1-click launcher:
   ```bash
   ./run.sh
   # Or navigate directly:
   cd voxflow/services/ml-engine
   python main.py
   ```
3. Open the browser UI:
   ```text
   http://127.0.0.1:8000/
   ```
4. Click Start listening and speak naturally.

## What the demo does

- Transcribes your voice in a lightweight local flow
- Cleans common filler words like “um” or “uh”
- Suggests a best word from the recognized text
- Shows the transcript in a web UI instantly

## Tips for better recognition

- Speak clearly and close to the microphone
- Reduce background noise
- Use short phrases first
- Try Chrome or Edge for the best browser voice support

High-Performance Refinement Pipeline

VoxFlow transforms raw spoken audio into production-grade text through an intelligent multi-layer pipeline.

STAGE 01
Audio / Text Capture

Real-time browser speech recognition or desktop hotkey stream captured via bidirectional WebSocket.

STAGE 02
Adaptive Memory

Identifies personal verbal habits, extracts bigrams, and dynamically suppresses high-frequency fillers.

STAGE 03
Rule-Based Normalizer

Normalizes informal contractions (wanna → want to), fixes punctuation, and applies casing rules.

STAGE 04
Local ML Refinement

Applies zero-hallucination on-device rewrites, resolves mid-sentence self-corrections, and builds Markdown summaries.
